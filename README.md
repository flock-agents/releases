# Flock Agents — Releases

[![Latest Release](https://img.shields.io/github/v/release/flock-agents/releases?label=latest)](https://github.com/flock-agents/releases/releases/latest)

This repository hosts official release binaries for [Flock Agents](https://flockagents.ai). Source code is maintained in a private repository.

## macOS

Download the latest `.dmg` from the [Releases page](https://github.com/flock-agents/releases/releases/latest).

1. Download `Flock-<version>.dmg`
2. Open the `.dmg` and drag **Flock** to your Applications folder
3. Launch Flock from Applications

## Docker

```bash
docker pull ghcr.io/flock-agents/flock:latest
```

To run:

```bash
docker run -d --name flock ghcr.io/flock-agents/flock:latest
```

See the [Releases page](https://github.com/flock-agents/releases/releases) for all available tags.
